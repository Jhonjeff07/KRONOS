# Kronos
Planea tu tiempo y mide en qué se va. App web (PWA) sin compilación: solo archivos estáticos.

Publicar en GitHub Pages: Settings > Pages > Deploy from a branch > main / (root).
Autorizar el dominio `TU-USUARIO.github.io` en Firebase > Authentication > Configuración > Dominios autorizados.
Las reglas de Firestore están en REGLAS_FIRESTORE.txt.
