Pega esto en Firebase > Firestore Database > pestaña "Reglas" y pulsa "Publicar":

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /users/{userId} {
      allow read, write: if request.auth != null && request.auth.uid == userId;
    }
  }
}

Con esto cada persona solo puede leer y escribir su propio documento.
